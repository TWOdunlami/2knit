# TWO CRAFTS: Knitting Pattern

This website was created to share easy knitting patterns FOR FREE TO ALL VISITORS. The patterns are intended for beginners. All patterns can be republished with/without credit. All images saved in th efolder file are from my completed projects. The others are open source


## Dependencies

* No prerequisites, libraries, or OS versions needed to run this website.
* ex. Windows 10 or OSX 10.
* This website uses cha support through a 3rd-party website MYLIVECHAT.COM

### Pattern Notes

* All patterns are free and do not require the user to click on a download link.
* All visitors are welcome to send feedback to improve the patterns
