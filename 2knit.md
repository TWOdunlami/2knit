# TWO CRAFTS: Knitting Pattern

This website was created to share easy knitting patterns. This intended for beginners. All patterns are free and can be republished with/without credit.


## Dependencies

* No prerequisites, libraries, or OS versions needed to run this website.
* ex. Windows 10 or OSX 10

### Pattern Notes

* All patterns are free and do not require the user to click on a download link.
* All visitors are welcome to send feedback to improve the patterns
